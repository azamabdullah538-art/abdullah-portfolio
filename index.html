UI/UX design in Figma

I plan the experience first, then design it in Figma before writing code, so the build matches a clear plan.

  1. 1

    Understand

    Define who the page is for and what they need to do, then map the key user flows.

  2. 2

    Wireframe

    Sketch low-fidelity layouts to settle structure and content order before styling.

  3. 3

    Design

    Build high-fidelity screens with Figma components, a colour palette and a type scale.

  4. 4

    Prototype and build

    Link screens into a clickable prototype, then translate the design into responsive code.
